# Demonstration Workflows

Three end-to-end workflows that show the QuPath-MCP interaction pattern —
**inspect → execute → verify → reproduce**. Each directory contains the natural-language
prompt, the exact JSON-RPC tool-call trace, the output artifacts, a screenshot, and the
success criteria (including the replay check for workflow 3).

| # | Workflow | Demonstrates | Writes? |
|---|----------|--------------|---------|
| [01](01-state-inspection/) | State inspection & annotation summary | Agent understands state before acting | No |
| [02](02-cell-detection-export/) | Cell detection & measurement export | Real analysis, verified before/after, CSV export | Yes |
| [03](03-record-replay/) | Workflow recording & deterministic replay | Reproducibility without an LLM | Yes |

## Input data

All traces were run against QuPath's public **LuCa-7color** multiplex immunofluorescence sample
(`LuCa-7color_[13860,52919]_1x1component_data.tif`), an **8-channel** component image (seven markers —
PDL1, CD8, FoxP3, CD68, PD1, CK, DAPI — plus autofluorescence). It ships as a QuPath sample image, so
the workflows are reproducible by anyone.

## How to reproduce

1. Launch QuPath with the server (see [`../docs/quick_start.md`](../docs/quick_start.md)).
2. Open the LuCa-7color sample and set the image type to *Fluorescence*.
3. Replay a trace's requests with `curl` (bodies are in each `trace.jsonl`), or hand the prompt to
   an MCP-connected agent and let it drive the tools.

## Provenance of these artifacts

The screenshots and reported counts here were captured from **live runs during development** on the
LuCa-7color image (cell detection reproducibly yields **5266 nuclei**, confirmed in the QuPath run
logs). The `trace.jsonl` files give the real request bodies and the salient real response fields; the
measurement CSV is shipped as a schema + representative excerpt (the full table is 5266 rows × 134
columns and is regenerated by `qupath_export_measurements` at run time — see that file's header).
